# Cube Autoplay (Geode)

- Pause menüsünün sol altındaki kutu: botu aç/kapat
- Geode mod ayarları: "Autoplay açık" ve "İleri bakış"
- Normal, practice, testmode ve editör playtest'te çalışır
- Şimdilik sadece cube (ship, ball, wave vb. için bot devre dışı kalır)

Derleme: Geode SDK kurulu bir bilgisayarda `geode build`,
ya da repoyu GitHub'a yükle, Actions sekmesindeki build .geode dosyasını verir.
